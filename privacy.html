隐私政策

先说明白：资料在哪里，什么时候会离开设备，以及怎样把它们带走或删除。

更新日期：2026 年 11 月 25 日

录音与文字保存在你自己的设备上。我们没有任何服务器接收你的录音和文字。云端模型是可选项，是否使用、使用哪一家服务，由你决定。

一、适用范围

本政策适用于美若清提供的念记 iPhone 与 Apple Watch App，以及本官网。美若清的运营主体为深圳美若轻生物科技有限公司，所在地为深圳。

念记把你主动记录的闪念、全天录音和导入的文字整理为个人资料。本政策说明这些内容如何被处理，以及你可以如何管理。

二、录音、本机转写与原音回听

你发起闪念或全天录音并授予麦克风权限后，念记会记录声音。全天录音支持按 10、20 或 30 分钟自动分段保存；已经保存的分段，不会因后续录音中断而一并丢失。录音可能包含他人的声音，请尊重相关人员的知情与隐私。

录音与文字存放在你的手机上。念记支持直接在手机上转写，提供全天逐字稿和部分逐字稿，失败的分段可以单独重新转写。使用本机转写时，不需要把录音发送给我们。

逐字稿的段落与原音关联，便于回听核对。清掉原音后，文字仍会保留；对应的原音将无法继续回听。

三、你选择使用云端模型时

云端模型不是必选项。你可以自行填写服务配置；执行云端转写或其他云端处理时，相关录音或文字会发送给你配置的服务提供方，而非美若清的数据服务器。

API Key 保存在这台设备的系统钥匙串中，用于你配置服务的请求鉴权。我们不代为保管你的密钥。本机保存密钥，不意味着请求鉴权时无需向你选择的服务发送凭据。

请在使用前了解服务商的数据用途、保存期限、处理地点与删除方式。第三方服务的数据处理适用其自身政策；如果不想继续使用，请停止相关云端操作并管理或移除服务配置。已经发送的内容需要按该服务商的规则处理。

四、回顾、整理与个人积累

念记根据你的记录提供当日回顾、完整回顾、时段详情与时间线，支持查看当日、上一天、下一天，以及近一周和近一月。

可执行提示词、定向总结、“我的模板”、每日“善念与你”、一段时间的心情趋势，以及收藏与精选，均用于整理和回看你的个人记录。相关资料保留在你自己的设备上；需要云端服务参与的处理，由你选择和配置。

当你把生成的提示词复制到其他 AI 或应用时，相关内容会由你选择的工具接收，其后续处理适用该工具的政策。

五、历史资料、Apple Watch 与导出

你可以导入 Markdown 或纯文本，将历史资料纳入知识库，与今天的记录一起检索和回顾。

Apple Watch 可以单独录音。回到 iPhone 附近并具备传输条件时，录音会自动交给手机转写和处理。设备间交接不经过美若清的录音存储服务器。

念记支持导出完整备份、某天的原文 Markdown 和逐字稿，文字按天自动归档为文件夹。导出文件由你选择保存位置；复制到其他设备、云盘或应用后的副本，需要在相应位置另行管理。

六、保存、删除与副本管理

资料由你保管。删除前，请先导出需要保留的内容，并确认导出文件可以正常打开。只清掉原音会保留文字；如需移除本机 App 数据，可以使用 iOS 的“删除 App”操作。“从主屏幕移除”或“卸载 App”不等同于删除全部 App 数据。

删除手机上的 App，不会自动清除已导出的文件、其他设备副本或已有系统备份。请分别检查 Apple Watch、文件保存位置和使用过的备份服务，并删除其中不再需要的资料。若系统备份包含念记内容，其管理和删除遵循相应系统或服务的规则。

API Key 也需要单独处理，不应只依赖删除 App 来清除钥匙串项目。需要立即使密钥失效时，请在对应模型服务商处撤销密钥。已发送到第三方的内容，请按该服务商的规则申请处理。

我们没有你的录音与文字服务器副本，无法从服务器替你恢复已经删除的本机资料。

七、权限与数据使用原则

麦克风权限用于你主动发起的录音。你可以在系统设置中随时撤销权限；撤销后，相关录音功能将无法使用。

我们不出售你的个人数据，不做用户画像，也不把你的个人记录用于广告投放。念记无订阅、无内购、无广告。你自行配置的第三方服务可能另行收费，具体由该服务商决定。

请妥善保护设备解锁凭据与 API Key。共享设备或导出文件前，请检查其中是否包含不希望公开的内容。

八、官网访问与支持邮件

本官网是静态网站，未加入广告、访问分析脚本、追踪 Cookie 或资料上传表单。网站托管服务商可能为提供访问服务处理必要的网络信息；这与念记 App 录音和文字的本机保存相互独立。

你主动通过邮件联系时，我们会收到你的邮箱地址和邮件内容，用于处理相关咨询。请不要发送 API Key、设备密码或不必要的完整录音；需要处理支持邮件中的个人信息时，可通过同一邮箱联系我们。
