开始记录

录音权限怎么给？

第一次开始录音时，允许念记使用麦克风。如果之前拒绝过，在 iPhone 的“设置 → 隐私与安全 → 麦克风”中开启念记的权限。若列表中没有念记，先回到 App 尝试开始一次录音，再检查权限列表。

锁屏或切到后台后，录音会不会停止？

念记支持持续录音和分段保存，但来电、系统音频中断、设备关机或强制退出 App 等情况可能打断录音，不能保证所有情况下都连续运行。

开始较长录音前，检查电量和可用空间。发生中断后，回到念记确认状态；已保存的分段会保留。

iPhone 背面轻点两下怎么设置？

在支持该功能的 iPhone 上，进入“设置 → 辅助功能 → 触控 → 轻点背面”，为“轻点两下”选择相应操作，并按念记实际提供的配置方式完成关联。系统名称可能随版本不同；若找不到对应操作，请联系我们协助确认。

设置完成后先试录一小段，确认轻点两下可以开始、再轻点两下可以结束。也可以直接在念记首页使用轻点两下。

Apple Watch 录的内容怎么回到手机？

Apple Watch 可以单独录音，回到 iPhone 附近时会自动把录音交给手机转写和处理。如果暂时没看到，先确认两台设备的连接状态，再在手机上检查录音与处理结果。

确认交接完成前，保留手表上的录音，不要删除 App 或抹掉手表。

转写与整理

转写失败了怎么办？

先保留原音，找到失败的分段，单独重新转写即可，不必重做整天的记录。本机转写可先检查可用空间与 App 状态；使用自配云端模型时，还需检查网络、服务配置、API Key 是否有效和服务是否可用。

如果仍然失败，请把错误提示发给我们，不要发送密钥。

能不能更换转写模型？

可以使用手机上的转写，也可以自行配置云端模型并调整服务配置。具体模型是否可用，取决于它与念记所支持接口的兼容情况。修改后建议先测试较短的分段，保留尚未成功转写的原音。

云端服务的收费和数据处理规则由相应服务商决定。

怎么导入历史资料？

在知识库中导入 Markdown 或纯文本文件。导入后，过去写下的东西与今天的记录可以一起被检索和回顾。建议保留原文件，先导入一份较小的资料，确认文字显示正常。

清掉原音后，文字会一起消失吗？

不会。清掉原音后，逐字稿仍然保留，但对应段落无法再回听。如果以后还需要核对当时的说法，请先保留相关原音。

可执行提示词可以交给哪些 AI？

从当天记录生成提示词后，可以复制到你选择的任意 AI 中使用。定向总结和“我的模板”可以帮助你调整整理方向。

发送前，请检查其中是否包含不想交给第三方的内容。被复制过去的资料将由对应 AI 服务接收。

带走与管理资料

怎么导出自己的资料？

念记提供完整备份、某天的原文 Markdown 和逐字稿导出。按需要选择范围，并保存到自己的文件位置。文字按天归档为文件夹；导出后先打开检查，再进行清理或迁移。

换了手机怎么迁移？

先在旧手机导出完整备份，并另外保存重要日期的 Markdown 或逐字稿。新手机可以通过知识库导入 Markdown 或纯文本，将这些文字作为历史资料保留。

如果还需要迁移原音、原音与文字的关联、收藏或其他 App 状态，请先联系我们确认适合的迁移方式。确认新手机资料完整前，保留旧手机和导出文件。

怎么彻底删除数据？

确认不再需要保留后，可以通过 iOS 的“删除 App”移除本机 App 及其数据；仅从主屏幕移除或“卸载 App”不是同一件事。还需分别处理 Apple Watch 中的录音、导出文件、其他设备副本与已有备份。

API Key 需要单独处理，必要时在服务商处撤销；已经发送给云端模型的内容，也需按该服务商的规则申请删除。完整说明见隐私政策中的保存与删除。

有订阅、内购或广告吗？现在能下载吗？

念记无订阅、无内购、无广告。自行配置的云端模型服务可能由服务商另行收费。

App Store 下载链接尚未公布，官网入口将在链接确认后更新。
