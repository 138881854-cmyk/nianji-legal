支持

适用 念记 1.2.6（24）　·　iPhone iOS 18 及以上，Apple Watch watchOS 11 及以上

念记把你说的话整理成能长期带走的文字。录音默认只存在你的手机上。下面是常被问到的问题；没找到答案，直接发邮件。

我的录音存在哪里？

存在念记的应用沙盒里（Application Support 目录），文字存成数据库与 Markdown 文件。你可以在「资料库」里看，也可以开启文件共享后用系统「文件」App 打开。

删掉 App 会怎样？

沙盒内的全部录音、文字、回顾与配置会一起被清除，且无法恢复。念记不上传、不备份，所以我们这边没有副本可以帮你找回。如果这些内容重要，请先在设置里导出完整备份，或导出 Markdown 到自己的文件夹。

不联网能用吗？

录音不需要联网，全天记录和手表录音都可以离线进行。转写需要你配置的服务：没有网络时，可以用 iOS 自带的本机听写补转一部分；完全离线且没有可用语言包时，录音会保留原音，等有网络再转。

我在设置里填了自己的接口地址，数据会发到哪里？

只发到你填的那一个地址。当前版本念记没有中转服务器，请求由你的手机直接发出。你填的是哪家服务商，数据就由哪家处理，保存期限与用途适用对方的隐私政策。想完全不出设备，就不要填地址和密钥。

为什么出厂就填好了千问和 DeepSeek 的地址？

那只是给常见服务预置的地址模板，省去你查文档。密钥必须由你自己申请并填写，我们不提供、也不代管任何密钥。没有密钥，请求会被服务商拒绝，念记不会因此把数据发给别人。

转写不准、或者某一段失败了怎么办？

原音会保留在「整理状态」里，可以回听、可以只补转失败的那一片，也可以手动重试。转写准确性受口音、环境噪音、远场收音影响；手表在衣袖遮挡或运动喘气时尤其明显。被服务商拒收的片段不会被丢掉，原音仍可导出。

换手机怎么迁移？

在旧手机里导出完整备份（或导出 Markdown 到「文件」App、iCloud Drive、Obsidian），在新手机的「设置 → 知识库与迁移」里导入。App 不做云端同步，所以迁移要靠你手里的这份文件。

Apple Watch 录的音去哪了？

先存在手表上，再交给配对的 iPhone 处理。手机上会显示传输与转写的进度；手表不在手机附近时会等下一次连接。手表端不保存第二份长期副本。

密钥安全吗？

密钥只写入 iOS 钥匙串，标记为「仅本设备、首次解锁后可读」，不写日志、不导出、不随备份迁移。念记没有任何后台可以读取它。

会员是什么？怎么收费？

会员是可以按月购买的服务（例如 29 元或 39 元一档），买的是转写额度和撰写次数，不用自己申请各家 API 的密钥。具体价格、包含内容和周期，以 App 内和 App Store 页面显示为准。

会员的录音会被你们看到吗？

不会。会员模式下，音频和文字只是从我们服务器转发给模型服务，转发在内存里完成，请求结束即丢弃。我们不落盘、不建副本、不做人工查看，也不用于训练模型。我们只保留不含内容的计费记录（时间、类型、时长或字数、状态码、会员标识），保存 12 个月。

怎么取消订阅？怎么退款？

取消：iOS「设置 → 顶部 Apple ID → 订阅 → 念记 → 取消订阅」，当期到期后不再扣费。退款：由 Apple 按 App Store 规则处理，在 Apple 的「报告问题」页面申请，我们无权代退。已使用的额度不因取消而退还。

怎么一次性删掉所有数据？

删除 App 即清除沙盒内全部数据。如果你有会员账号，请在「设置 → 会员 → 注销」完成注销，我们会一并删除会员标识与用量记录。曾导出到「文件」App、iCloud Drive、Obsidian 或其他网盘的副本，需要你在那些位置另行删除。
